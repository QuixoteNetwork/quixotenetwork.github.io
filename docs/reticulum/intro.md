# 📘 Introducción a Reticulum

## ❓ ¿Qué es Reticulum?

**Reticulum** es un proyecto *Open Source* de red autónoma y descentralizada, diseñado para permitir comunicaciones seguras y resilientes sobre múltiples medios de transporte, sin depender de infraestructuras centrales.

En **Quixote Network**, Reticulum se utiliza como una pieza clave para experimentar con **redes distribuidas**, **servicios autónomos** y **comunicaciones tolerantes a interrupciones**, alineadas con los principios de descentralización y resiliencia de la red.


---

## 🧩  Comenzar con Reticulum

Primeros pasos para empezar a utilizar Reticulum y Nomad Network:

- Instalar tu RNS: https://reticulum.network/manual/gettingstartedfast.html

- Configurar tu nodo con conexión a internet con una interfaz Auto o TCPServerInterface.
  
- Configurar tu RNS con varios de estos Servidores RNS: https://quixote.info/docs/reticulum/servidores
  
- Instalar un navegador para Nomad Network y/o Mensajería:

  - **MeshChat** (Entorno Gráfico Multiplataforma): https://github.com/liamcottle/reticulum-meshchat *(fácil uso, ideal para inciarse)*
  - **Columba** (para Android): https://github.com/torlando-tech/columba *(fácil uso, ideal para inciarse)*
  - Nomadnet (Navegador en Línea de Comandos): https://github.com/markqvist/NomadNet
  - Sideband (sólo mensajería para Android): https://github.com/markqvist/Sideband
  - rBrowser (Aplicación web): https://github.com/fr33n0w/rBrowser


- Ahora ya puedes empezar a Explorar y Probar. Y sobre todo leer y preguntar 😉
