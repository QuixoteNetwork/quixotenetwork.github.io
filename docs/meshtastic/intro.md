# 📘 Introducción a Meshtastic

## ¿Qué es Meshtastic?

**Meshtastic** es una red de comunicaciones mallada basada en radio de baja potencia (LoRa), diseñada para intercambiar mensajes y datos de forma descentralizada, sin depender de infraestructuras centrales ni de conexión a Internet.

En **Quixote Network** utilizamos Meshtastic como una de las tecnologías clave para construir redes **resilientes**, **distribuidas** y **autónomas**, complementando otros sistemas de comunicación como la radio HF y los modos digitales.

## Canal utilizado: **Iberia**

Dentro de la red Meshtastic, Quixote Network opera utilizando el canal: Iberia

Este canal común permite:
- Facilitar la interoperabilidad entre nodos
- Unificar criterios de operación
- Favorecer la comunicación entre participantes de distintas zonas
- Construir una red mallada coherente a escala regional

Cada participante debe configurar su nodo siguiendo las recomendaciones publicadas en **Meshtastic.es**, asegurándose de actuar siempre dentro del marco legal correspondiente.

---

## Meshtastic dentro de Quixote Network

El uso de Meshtastic en Quixote Network está orientado a:

- Experimentar con **redes malladas reales**
- Desplegar nodos autónomos y enlaces distribuidos
- Probar escenarios de **comunicación sin infraestructura**
- Integrar Meshtastic con otras tecnologías y redes experimentales

Meshtastic aporta una base sólida para la comunicación local y regional, reforzando la resiliencia global de la red.
