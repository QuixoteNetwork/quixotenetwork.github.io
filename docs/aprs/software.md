# 💻 Software APRS: Programas principales por sistema operativo

Esta es una recopilación de los programas más utilizados para trabajar con **APRS**, organizados por plataforma.


## 📱 Android

### 📡 APRSdroid (versión Google Play)
Cliente APRS original para uso móvil con soporte GPS, mapas y mensajería. Esta versión actualmente está sin actualizar.

🔗 https://play.google.com/store/apps/details?id=org.aprsdroid.app

---

### 📡 APRSdroid NA7Q (versión Open Source actualizada)
Versión mejorada, con más funcionalidades y en pleno desarrollo, actualmente es la versión recomendada.

🔗 https://na7q.com/aprsdroid-osm/

---

## 🪟 Windows

### 📡 PinPoint APRS
Cliente APRS muy completo con mapas, tracking y soporte RF/Internet.

🔗 https://www.pinpointaprs.com/

---

### 📡 YAAC (Yet Another APRS Client)
Cliente moderno, multiplataforma y muy potente basado en Java.

🔗 https://www.ka2ddo.org/ka2ddo/YAAC.html

---

### 📡 UI-View32
Clásico cliente APRS para Windows (ya sin desarrollo activo, pero aún usado).

🔗 http://www.ui-view.net/

---

## 🐧 Linux

### 📡 Xastir
Cliente APRS muy completo y ampliamente utilizado en Linux.

🔗 https://xastir.org/

---

### 📡 YAAC (Java)
También disponible en Linux.

🔗 https://www.ka2ddo.org/ka2ddo/YAAC.html

---

## 🍎 macOS

### 📡 YAAC
Una de las mejores opciones APRS para macOS.

🔗 https://www.ka2ddo.org/ka2ddo/YAAC.html

---

### 📡 Xastir
También puede ejecutarse en macOS (configuración más avanzada).

🔗 https://xastir.org/

---

### 📡 Direwolf
TNC por software (soundcard) para usar APRS sin hardware dedicado.

🔗 https://github.com/wb2osz/direwolf

## 🧰 Notas

- **Direwolf** permite usar APRS solo con una tarjeta de sonido  
- **YAAC** es una opción muy completa y multiplataforma  
- **APRSdroid** es ideal para uso portátil  
- **PinPoint** destaca por su interfaz sencilla en Windows  

---

## 📡 Recomendación rápida

- 📱 Android → APRSdroid NA7Q
- 🪟 Windows → PinPoint APRS / YAAC  + Direwolf
- 🐧 Linux → Xastir + Direwolf  
- 🍎 macOS → YAAC
