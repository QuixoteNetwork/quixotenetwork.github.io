# 📡 Tipos de Estaciones APRS

En APRS existen diferentes tipos de estaciones, cada una con una función específica dentro de la red. Algunas ayudan a retransmitir paquetes, otras proporcionan acceso a internet, meteorología o servicios especiales.

---

<Tabs groupId="aprs-stations">

<TabItem value="igate" label="🌐 IGate">

# 🌐 iGate (Internet Gateway)

**Radio ↔ APRS-IS (Internet)**

## Símbolo APRS recomendado

`I&` → Diamond / Gateway

## Funciones

- Envía paquetes RF a internet
- Recibe paquetes desde internet
- Permite comunicación global
- Muy útil para cobertura extendida

## Ejemplo

`EA1QXT-10`

</TabItem>

<TabItem value="digipeater" label="📻 Digipeater">

# 📻 Digipeater

**Radio ↔ Radio**

## Símbolo APRS recomendado

`#` → Digipeater

## Funciones

- Repetir paquetes APRS
- Extender alcance de estaciones móviles
- Crear cobertura regional

## Alias comunes

- `WIDE1-1`
- `WIDE2-1`
- `WIDE2-2`

## Ejemplo

`EA4XYZ-1`

</TabItem>

# 🛜 APRS-IS Core Servers

**Infraestructura global de internet para APRS**

## Símbolo recomendado

`No suelen usar símbolo APRS RF`

Porque normalmente:
- no transmiten directamente por radio
- funcionan únicamente sobre internet
- forman parte del backbone APRS mundial

## ¿Qué es APRS-IS?

APRS-IS (**Automatic Packet Reporting System Internet Service**) es una red mundial de servidores conectados entre sí que distribuyen tráfico APRS a través de internet.

Gracias a APRS-IS:
- los paquetes APRS pueden verse globalmente
- aplicaciones como APRSdroid o aprs.fi muestran estaciones en tiempo real
- los IGates pueden enviar y recibir tráfico desde internet
- los mensajes APRS pueden viajar a grandes distancias

## Funciones principales

- Distribuir tráfico APRS mundial
- Interconectar IGates
- Sincronizar mensajes APRS
- Compartir posiciones GPS
- Compartir telemetría y WX
- Permitir acceso global desde aplicaciones APRS

## ¿Cómo funciona?

```text
Radio APRS
    ↓
IGate
    ↓
APRS-IS
    ↓
Servidores APRS globales
    ↓
Otros IGates / Clientes APRS
````

## Servidores APRS-IS conocidos

* `rotate.aprs2.net`
* `euro.aprs2.net`
* `noam.aprs2.net`
* `cwop.aprs.net`

## Clientes típicos conectados a APRS-IS

* APRSdroid
* YAAC
* PinPoint APRS
* Xastir
* Direwolf
* aprs.fi
* QtTermTCP

## Importante

APRS-IS NO sustituye la radio.

La filosofía APRS sigue siendo:

```tip
RF first
```

Internet simplemente ayuda a:

* ampliar cobertura
* visualizar tráfico
* conectar regiones lejanas
* facilitar monitorización global
