# 📡 Tipos de Estaciones APRS

En APRS existen diferentes tipos de estaciones, cada una con una función específica dentro de la red. Algunas ayudan a retransmitir paquetes, otras proporcionan acceso a internet, meteorología o servicios especiales.

---

<Tabs>

<TabItem value="igate" label="🌐 IGate">

# 🌐 IGate (Internet Gateway)

<pre>
Radio ↔ APRS-IS (Internet)
</pre>

## Símbolo APRS recomendado

<pre>
I&   (Diamond / Gateway)
</pre>

## Funciones

- Envía paquetes RF a internet
- Recibe paquetes desde internet
- Permite comunicación global
- Muy útil para cobertura extendida

## Ejemplo

<pre>
EA1QXT-10
</pre>

</TabItem>

<TabItem value="digipeater" label="📻 Digipeater">

# 📻 Digipeater

<pre>
Radio ↔ Radio
</pre>

## Símbolo APRS recomendado

<pre>
#    (Digipeater)
</pre>

## Funciones

- Repetir paquetes APRS
- Extender alcance de estaciones móviles
- Crear cobertura regional

## Alias comunes

<pre>
WIDE1-1
WIDE2-1
WIDE2-2
</pre>

## Ejemplo

<pre>
EA1QXT-1
</pre>

</TabItem>

<TabItem value="wx" label="🌦️ WX">

# 🌦️ WX Station (Weather Station)

<pre>
Meteorología APRS
</pre>

## Símbolo APRS recomendado

<pre>
_    (Weather Station)
</pre>

## Datos típicos

- Temperatura
- Humedad
- Presión
- Velocidad del viento
- Lluvia

## Ejemplo

<pre>
EA4WX-13
</pre>

</TabItem>

<TabItem value="mobile" label="🚗 Móvil">

# 🚗 Mobile Station

<pre>
Estación móvil APRS
</pre>

## Símbolo APRS recomendado

<pre>

</pre>

<pre>
[    (Jeep / 4x4)

## Funciones

- Tracking en tiempo real

- Rutas y desplazamientos

## Ejemplo

<pre>
EA1QXT-9
</pre>

</TabItem>
