# 📡 Tipos de Estaciones APRS

En APRS existen diferentes tipos de estaciones, cada una con una función específica dentro de la red. Algunas ayudan a retransmitir paquetes, otras proporcionan acceso a internet, meteorología o servicios especiales.

---

<Tabs groupId="aprs-stations">

<TabItem value="igate" label="🌐 IGate">

# 🌐 IGate (Internet Gateway)

**Radio ↔ APRS-IS (Internet)**

## Símbolo APRS recomendado

`I&` → Diamond / Gateway

## Funciones

- Envía paquetes RF a internet
- Recibe paquetes desde internet
- Permite comunicación global
- Muy útil para cobertura extendida

## Ejemplo

`EA1QXT-10`

</TabItem>

<TabItem value="digipeater" label="📻 Digipeater">

# 📻 Digipeater

**Radio ↔ Radio**

## Símbolo APRS recomendado

`#` → Digipeater

## Funciones

- Repetir paquetes APRS
- Extender alcance de estaciones móviles
- Crear cobertura regional

## Alias comunes

- `WIDE1-1`
- `WIDE2-1`
- `WIDE2-2`

## Ejemplo

`EA4XYZ-1`

</TabItem>

<TabItem value="wx" label="🌦️ WX">

# 🌦️ WX Station (Weather Station)

**Meteorología APRS**

## Símbolo APRS recomendado

`_` → Weather Station

## Datos típicos

- Temperatura
- Humedad
- Presión
- Velocidad del viento
- Lluvia

## Ejemplo

`EA4WX-13`

</TabItem>

<TabItem value="mobile" label="🚗 Móvil">

# 🚗 Mobile Station

**Estación móvil APRS**

## Símbolos APRS recomendados

- `>` → Car
- `[` → Jeep / 4x4
- `<` → Motorcycle
- `b` → Bike

## Funciones

- Tracking en tiempo real
- Telemetría móvil
- Rutas y desplazamientos

## Ejemplo

`EA1QXT-9`

</TabItem>

**Estación fija APRS**

## Símbolo APRS recomendado

`-` → House / Home Station

## Funciones

- Monitorización APRS

- Mensajería

## Ejemplo

`EA1QXT`

</TabItem>

<TabItem value="satellite" label="🛰️ Satélite">

# 🛰️ Satellite Gateway

**APRS vía satélite**

## Símbolo APRS recomendado

`S` → Satellite

## Funciones

- APRS global
- Tracking satelital
- Mensajería vía satélite

## Satélites típicos

- `ISS`
- `NO-84`
- `PSAT`

</TabItem>

**Telemetría APRS**

## Símbolo APRS recomendado

## Datos típicos

</TabItem>

<TabItem value="object" label="🚑 Objetos">

# 🚑 Object / Event Station

**Objetos y eventos APRS**

## Símbolos recomendados

- Emergencias
- Carreras
- Refugios

</TabItem>

# 📡 APRS Messaging Station

**Mensajería APRS**

`M` → Message Center

<TabItem value="services" label="🤖 Servicios">

# 🤖 APRS Service Stations

**Servicios automáticos APRS**

## Símbolo APRS recomendado

`?` → Info / Service

- `EMAIL`

</TabItem>

<TabItem value="aprsis" label="🛜 APRS-IS">

# 🛜 APRS-IS Core Servers

**Infraestructura APRS Internet**

## Símbolo recomendado

`No suelen usar símbolo APRS RF`

Porque normalmente:

- no transmiten RF
- funcionan solo en APRS-IS

</TabItem>

**Digipeater local de apoyo**

`WIDE1-1`

</TabItem>

<TabItem value="tracker" label="🧭 Tracker">

# 🧭 Tracker APRS

**Baliza APRS GPS**
