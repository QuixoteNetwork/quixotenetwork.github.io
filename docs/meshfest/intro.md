# 📘 Introducción a MesHFest


MeshFest-Lite es una aplicación ligera y sencilla diseñada tanto para comunicaciones de texto/ficheros punto a punto, como para actuar como puente de comunicaciones entre redes Meshtastic y modos digitales de HF (Banda Ciudadana, 20m, 40m...) como VARA HF o JS8Call (todavía sin soporte).

Permite la interconexión entre redes Meshtastic y Estaciones de Radio HF, facilitando el envío y recepción de mensajes entre ambas infraestructuras de forma transparente.

La aplicación funciona como una pasarela inteligente capaz de:
- Reenviar mensajes
- Formatear datos
- Gestionar ACKs (confirmaciones)
- Enrutar comunicaciones entre distintas tecnologías

De este modo, estaciones operando en HF pueden comunicarse con nodos Meshtastic y viceversa.

---

## ⚙️ Concepto

MeshFest-Lite es una versión simplificada (archivo de código único) diseñada para:

- Poder ejecutarse como servicio
- Funcionar como bridge/chat ligero
- Operar de forma autónoma (unattended)
- Desplegarse en entornos portables o de bajos recursos
- Funcionar en una Estación 24/7 tanto como Bridge como BBS de HF

Es ideal cuando se prioriza la estabilidad, simplicidad y bajo consumo.

---

## 🚀 Características principales

- 🔁 **Bridge bidireccional** (Meshtastic ↔ HF)
- 📬 **Reenvío automático de mensajes**
- ✅ **Gestión de ACKs y confirmaciones**
- 🧭 **Enrutamiento basado en Indicativo**
- ⚡ **Arquitectura ligera y orientada a servicios**
- 🛰️ **Diseñado para experimentación y comunicaciones de Sin Internet, Offgrid o Emergencia**
- 🌐 **Soporte para redes RF híbridas**

---

## 📁 Funcionalidades adicionales

- 📦 **Envío y recepción de archivos entre estaciones HF**  
  *(no disponible para Meshtastic)*

- 🗂️ **Sistema BBS (Bulletin Board System)**  
  Permite descargar archivos desde otras estaciones MeshFest  
  *(no disponible para Meshtastic)*
  
- 📊 **Permite enviar archivos a otras Estacionesd HF**
  *(no disponible para Meshtastic)*
---

## 🌍 Objetivo

MeshFest-Lite permite la creación de ecosistemas de comunicación híbridos donde Meshtastic y la radio digital HF coexisten y se complementan, ampliando significativamente las capacidades de comunicación en entornos sin infraestructura convencional. Está especialmente pensado para comunicar mallas de Meshtastic a muy larga distancia (50-500km) sin necesidad de tener nodos en posiciones privilegidas o donde es imposible por no existir puntos de altura que permitan comunicación en Línea de Visión.
